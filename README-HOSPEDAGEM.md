# COMO HOSPEDAR GRATIS NO RENDER

1. Crie conta no GitHub
2. Crie um repositório novo
3. Envie TODOS os arquivos desta pasta
4. Entre em https://render.com
5. Login com GitHub
6. Clique em New +
7. Web Service
8. Selecione o repositório
9. O Render vai detectar automaticamente o Dockerfile
10. Clique em Deploy
